# Proposta de Site RLSN

Proposta comercial de sites e páginas de vendas.

## Publicação

- GitHub Pages: publicado a partir da raiz da branch `main` (https://rlsn3.github.io/propostadesite/).
- Cloudflare Workers (opcional): `wrangler.jsonc` publica a raiz do repositório; `.assetsignore` exclui os arquivos de configuração.

Para atualizar a proposta, substitua `index.html`.
